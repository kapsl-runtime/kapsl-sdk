# kapsl-llama-cpp-sys-2

Kapsl-maintained raw bindings to the pinned `llama.cpp-kapsl` fork, including
the shared-KV and device-memory reporting ABI used by the Kapsl runtime.

See [kapsl-llama-cpp-2](https://crates.io/crates/kapsl-llama-cpp-2) for the
safe wrapper. This package is derived from `llama-cpp-sys-2` and retains its
MIT OR Apache-2.0 license.
